# CRM Un Producto (Static HTML)
CRM tipo Xubio para un solo producto. Frontend 100% estático (HTML + CSS + JS), persiste en localStorage.

## Demo local
Abre `index.html` en tu navegador.

## Deploy desde GitHub a Netlify
1. Crea repo en GitHub y sube estos archivos.
2. Netlify → Add new site → Import from GitHub.
3. Build command: *(vacío)*, Publish directory: `/`.
4. Deploy.
